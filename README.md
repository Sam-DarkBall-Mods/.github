# Sam-DarkBall-Mods community files

GitHub uses this repository for the default contribution and security files in
the Sam-DarkBall-Mods organization. It also contains the issue forms and pull
request template shared by the mod repositories.

Most contributors do not need to clone this repository. Open an issue here only
when the problem concerns the organization itself rather than one of the mods.

Maintainers can find the release requirements in [RELEASING.md](RELEASING.md).
